# PP-502 — Shipment Status Lifecycle

## Test Cases

#### TC-PP502-ST-001 — Created → PickedUp

- **Type:** Positive
- **Priority:** High
- **Preconditions:** An existing shipment is in `Created` status.
- **Test data:** Current status = `Created`; requested status = `PickedUp`.
- **Test steps:**
  1. Open the shipment record.
  2. Confirm its current status is `Created`.
  3. Request a change to `PickedUp`.
  4. Save or submit the change.
  5. Retrieve the shipment record again.
- **Expected result:** The update is accepted, and the persisted status is `PickedUp`.
